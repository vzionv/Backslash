# 用户级功能与异常操作测试矩阵

状态：

- **实现审查**：已沿页面、组件、API、数据库和存储调用路径审查。
- **离线实测**：无需完整依赖/浏览器即可实际运行的脚本或仿真已通过。
- **浏览器待测**：必须启动完整 Web/WS 并实际点击，当前因依赖无法安装而阻塞。

任何“实现审查”都不等于浏览器行为已经通过。

## 10. 浏览器 E2E 通过条件

发布前至少应在 Chromium 与 Firefox 各执行一次完整矩阵，并保存：网络请求/状态码、控制台错误、屏幕录像、服务日志、Node RSS/heap、TeX 子进程数量、SQLite/WAL 大小和失败后的磁盘状态。每个按钮需覆盖正常点击、快速双击、重复提交、返回/刷新、断网后重试、权限不足和后端 4xx/5xx。


## 11. 本次发布审查新增回归项

- `latexmk` 仅通过 PATH 提供时，启动环境检测不得误报缺失。
- 128 KiB 以上构建日志的内部 WS 事件应成功；超过配置上限应返回 413。
- 登录身份与匿名分享身份不得在同一 socket 上切换；登录用户通过无成员权限的公开链接访问时不得泄露账户身份。
- `CORS_ORIGIN=*` 与 `LATEX_ALLOW_SHELL_ESCAPE=true` 均必须有显式风险确认。
- 修改/删除协作者、关闭或更新公开链接、删除项目后，已连接 WS 客户端应立即重新鉴权；权限过期应在周期复核后断开。
- pnpm 安装必须允许 `better-sqlite3` 执行其必需的原生安装脚本。
